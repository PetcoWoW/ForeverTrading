The Wolf of Booty Bay - prices companion
==========================================

Fresh auction prices in your addon without waiting for your addon manager.

What it does
- Sits by the clock (a wolf in the system tray).
- Every 15 minutes it checks when the newest prices are from (a tiny download).
- When they're newer than the ones in your addon, it downloads them into the addon's folder and tells you:
  type /reload in game to load them. The game only reads files at login or /reload.
- Hover the wolf: what the game has loaded and what's ready. Right-click: Check now, Open the addon folder,
  Start with Windows, Quit.

Setup
1. Unzip this folder anywhere you'll keep it (Documents is fine).
2. Double-click "Start Wolf prices".
3. The first time, it asks whether to start with Windows.

If Windows shows "Windows protected your PC": click "More info", then "Run anyway". Or, before unzipping,
right-click the zip > Properties > tick "Unblock" > OK.

It finds World of Warcraft on its own; if it can't, it asks you to pick the "World of Warcraft" folder.

Light: it sleeps between checks (about 40-60 MB of memory, no CPU). Settings and a log are in
%APPDATA%\WolfPrices. To remove it: Quit from its menu, untick Start with Windows first, delete this folder.
